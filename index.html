Provisio

Dein Vertriebsplaner – lokal auf dem Gerät, verschlüsselt, ohne Konto.
Provisio öffnen

Öffne die App und lege sie dann auf deinen Home-Bildschirm – so läuft sie wie eine echte App.

iPhone / iPad In Safari öffnen

  1. Diese Seite in Safari öffnen und auf „Provisio öffnen" tippen.
  2. Unten auf das Teilen-Symbol tippen (Quadrat mit Pfeil nach oben).
  3. „Zum Home-Bildschirm" wählen, dann „Hinzufügen".

Wichtig: in Safari öffnen (nicht im In-App-Browser von WhatsApp o. Ä.), sonst fehlt „Zum Home-Bildschirm".

Android In Chrome öffnen

  1. Diese Seite in Chrome öffnen und auf „Provisio öffnen" tippen.
  2. Oben rechts auf das Menü (⋮) tippen.
  3. „App installieren" bzw. „Zum Startbildschirm hinzufügen" wählen.
So funktioniert's: Provisio speichert alle Daten verschlüsselt auf deinem Gerät – keine Anmeldung im Netz, keine Datenbank, komplett offline. Beim ersten Start legst du einen Zugang mit DK-Nummer und Passwort an und bekommst einen Wiederherstellungs-Code. Den gut aufbewahren.
